# Web Development Basics

This repository collects standalone HTML and CSS practice pages. The examples are independent files rather than one application, so there is no build step or common package setup.

## View an example

Open an `.html` file in a modern browser. Some pages reference local styles or assets; keep the repository's relative folder structure intact when opening them.

## Contents

The repository includes examples covering page structure, forms, positioning, layout, borders, and related HTML/CSS topics. It also contains a `Code with Harry` folder; retain source attribution and review its original terms before redistributing that material.

## Tests

No automated tests or lint configuration are present. Review each page manually in a browser.
